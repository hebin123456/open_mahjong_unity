# 萧山麻将规则 草稿

> 家庭房规 v2.0 · 对齐书面番种表 · 2026-10-20
>
> 与代码实现保持一致（`SoloPython/server/game_calculation/xiaoshan/rules.py` · `RULE_VERSION = "xiaoshan-house-2025-v2"`，v1 旧房间配置保持可读）。

## 一、牌与行牌

- 136 张牌（去掉 8 张花），十三张手牌，每家面前沏 17 墩；开局随机选庄，庄家掷骰开牌。
- **抢庄制**：谁胡谁做庄；流局庄家留任、连庄 +1。
- **仅自摸**：不能捉冲（无点炮）、不能抢杠胡。
- **翻财**：四家抓完后翻出牌墙所剩的那张牌为财神，是万能牌，场上同种财神仅剩 3 张；白板固定顶替翻出牌的本牌（如翻出 3 条，白板当 3 条用），本身不是万能牌；翻出白板时白板即财神。财神实体不可吃碰杠、不进副露，可打出。
- 打出财神后其他三家不能吃碰，打财神者可以吃碰。
- 允许吃张打张（如 456 条吃 7 条打 4 条）；已吃上家 2 摊后不允许吃张打张。

## 二、DIY 房规（创建房间可协商）

| 选项 | 可选值 | 默认 | 说明 |
|---|---|---|---|
| 底分 | 1（固定） | 1 | 结算基本分＝底分 × 总倍率 |
| 初始总分 | 0 / 50 / 100 / 200 | 100 | 0＝从零开始（旧对局兼容）；任一家持分变动以此为基准 |
| 倍率封顶 | 32 / 64 | 64 | 单份支付上限＝底分 × 封顶倍率；超出按封顶计 |
| 有财神必须爆头 | 开 / 关 | 关 | 开启时，含财神的和牌须财神做将；杠爆（杠后补牌恰摸进财神）、清一色、七对子豁免 |
| 积分小于 0 继续 | 开 / 关 | 关 | 关＝清零制：输家最多输光不出现负分，任一家 0 分整场结束；开＝可扣成负分，打满局数才收场 |
| 允许三摊承包 | 开 / 关 | 开 | 开启时对同一家累计吃碰满三摊触发承包/反承包；关闭后对同一家最多吃碰 2 摊，不触发承包（杠不属于摊，不受限） |

## 三、番种与倍数（倍率逐项相乘）

| 番种 | 倍数 | 说明 |
|---|---|---|
| 自摸 | ×1 | 底分基准 |
| 平和 | ×1 | 无其他番种时保底 |
| 爆头 | ×2 | 财神做将 |
| 大吊车 | ×2 | 单钓将：听牌仅剩唯一一张将牌（财神万能进张不参与唯一性判定） |
| 碰碰胡（大对子） | ×2 | 四组刻子/杠＋将 |
| 全倒 | ×2 | 四组面子全为明副露（无暗杠） |
| 无财神 | ×2 | 和牌手牌不含财神 |
| 明杠开 | ×2 | 明杠后补牌自摸 |
| 暗杠开 | ×4 | 暗杠后补牌自摸 |
| 财飘 | ×4/票 | 打出财神后自己摸和且财神做将，每票 ×4 累乘：一票 ×4、二票 ×16、三票 ×64 |
| 七对子 | ×4 | 有财神的七对 |
| 豪华七对 | ×2/组 | 七对子中每有一组实体四张同牌再 ×2：一杠 ×8、双豪华 ×16、三豪华 ×32 |
| 清一色 | ×8 | 全部同花色数字牌 |
| 乱风（全字胡） | ×32 | 全部字牌成和（原「字一色」提格） |
| 十风 | ×8 | 门清连续打出 10 张字牌后宣告；所弃十张含翻出的财神 ×16 |

**复合示例**（相乘后按封顶截断）：

- 杠爆（明杠）＝明杠开 ×2 × 爆头 ×2 ＝ 4；杠爆（暗杠）＝暗杠开 ×4 × 爆头 ×2 ＝ 8
- 七对子财票＝4 × 4＝16；七对财二票＝4 × 16＝64
- 清一色七对财票＝8 × 4 × 4＝128 → 封顶 64
- 清一色大对子大吊车爆头＝8 × 2 × 2 × 2＝64

**封顶**：单份支付上限＝底分 × 封顶倍率（默认 64 倍，可协商 32 倍）。

## 四、杠与飘附加

- **杠后和牌**：本局开过杠但和牌非杠开，每一杠向各家各收 1 番（+1 番/杠）。
- **飘失败**：打出财神后未飘成（别家先自摸），每飘向和牌家多付 1 番（+1 番/飘）。
- 附加在结算番种列表显示「+N 番」，支付明细为独立条目，受清零钳制。

## 五、老庄

- 一老庄 ×2、二老庄 ×4、三老庄 ×8 封顶（三连庄以上按三连庄算）；庄家一份按老庄倍数。
- 流局：庄家留任、连庄 +1。

## 六、承包

- **三摊承包**（DIY「允许三摊承包」默认开启）：对同一人累计吃碰满三次——你和牌时他全包；他和牌时你双倍全包（反承包）。
- 关闭「允许三摊承包」后，对同一家最多吃碰 2 摊，第三次吃碰该家不可用（杠不属于摊，不受限），承包不再触发。
- 承包者持分不足时按清零制扣至 0，不追讨。

## 七、天胡 / 地胡

- **天胡**：庄家开局第一巡自摸、全场无弃牌无副露 → 按封顶顶格（64 倍）结算，不再与其它番种相乘。
- **地胡**：闲家第一巡自摸、全场无副露 → 按封顶顶格（64 倍）结算，不再与其它番种相乘。

## 八、结算展示

- 番种列表：倍率条目显示「×N」，附加条目（杠后和牌/飘）显示「+N 番」。
- 支付明细逐条列出；清零制下持分不足部分不追讨。
- 庄家一份按老庄倍数；承包/反承包按责任支付。
